# 日々 ToDo

「日々ToDo.html」をブラウザーで開くか、`node server.mjs` を実行して http://127.0.0.1:4173 を開きます。
公開版: https://sakamototakurounin-glitch.github.io/hibi-todo/

## 頻度
各タスクに「何日に1回」と「週に何回」を両方設定します。
- N日に1回: 前回の完了日からN日経過すると必須。未完了のままなら必須表示を継続。最初は開始日が必須。
- 週N回: 月曜〜日曜で数える目標。間隔に余裕があっても週目標が未達なら半透明の候補として表示。
- 週目標を達成しても、間隔の必須条件は続きます。1日につき1回計上。
- 優先順: 必須（遅れている順）、週目標の候補、完了。候補は残り日数に対する未達回数で並べます。進行中は同じ優先度内で先に表示。
- 未来の完了記録は過去の日の判定に使いません。

## 保存・履歴
localStorageに利用者のブラウザーごとに保存します。編集は今日以降に適用し、過去の頻度と記録時のタスク名を残します。削除後も履歴は残ります。
旧タスクは過去の設定・履歴を保持して今日から両頻度へ移行します。旧「N日に1回」は週の回数を max(1, floor(7/N))、旧「週N回」は間隔を ceil(7/N) 日として補います。編集で変更できます。
保存失敗時は入力を残し、壊れたデータは上書きを停止します。ブラウザーのデータ消去や単体HTMLの移動・名前変更で保存場所が変わることがあります。

## 検証

実ブラウザーテスト: tests/browser.mjs と tests/extra-browser.mjs。両頻度登録・編集・必須・候補・並べ替え・保存・移行・履歴・320px表示・単体HTML・保存失敗を検証。
`node build-standalone.mjs` で単体HTMLを再生成します。
