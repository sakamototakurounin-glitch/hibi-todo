# To Do List

公開版: https://sakamototakurounin-glitch.github.io/hibi-todo/
「日々ToDo.html」は単体でブラウザーから利用できます。`node server.mjs` でも起動できます。

## タスク
- 定期: 間隔と週の回数を選択。どちらにも「設定しない」があります。
- 期限までに: 登録日から期限前は半透明の候補、期限当日から必須。
- 指定日に: 指定日から必須。
- 期限（指定日）の翌日になると、今日のタスクとタスク一覧から自動で非表示になります。データ・履歴・達成状況は残り、過去の日付を開けば当時の表示を確認できます。
- 定期の間隔: 前回の完了からN日経過すると必須。最初は開始日が必須。
- 定期の週目標: 月曜〜日曜。間隔に余裕があっても未達なら半透明の候補。
- 定期の両頻度が設定なし: 一度完了するまで候補として残ります。
- 必須（遅れた順）、候補、完了の順。完了を取り消すと戻ります。

## 画面
ToDoはタスク名と進捗操作だけを表示します。スクロール不要のホームで、件数が多い場合はページを切り替えます。
タスク一覧に設定を表示し、編集・削除できます。達成状況と履歴は別画面です。
進捗の丸で完了を切り替え、右端の状態アイコンで未完了→進行中→完了を切り替えます。

## 保存
localStorageにブラウザーごとに保存します。変更は今日以降に適用し、過去の設定・履歴を保持します。削除しても記録は残ります。
旧形式は今日以降から両頻度に変換します。旧「N日に1回」は週回数を max(1,floor(7/N))、旧「週N回」は間隔を ceil(7/N) として補います。編集で変更できます。
保存失敗時は入力を残し、壊れたデータは上書きを停止します。

## 追加画面の調整
間隔の選択肢は設定しない・1〜7日。開始日/実施日の入力幅は12remに制限。追加画面は上端と高さの上限を開いた時点で固定し、背景も固定します。閉じた後は固定を解除します。既存の8日以上の記録は保持し、編集画面では7日を初期選択にします。


## 必須表示
必須タスクは薄い赤で表示します。週回数が未達で、その日にまだ完了していない場合は、間隔に余裕があっても必須となります。進行中も必須。今日完了すると赤を解除して完了グループへ移動します。週達成後も間隔の必須条件は継続します。


追加・編集画面は高さと上端を固定。開始日・期限・実施日はラベル横の150pxの欄に短縮（小型画面は140px）。種類を切り替えてもダイアログ位置と高さを維持します。


## 週目標の必須判定（更新）
残り必要回数が今日を含む月曜〜日曜の残日数以上なら必須。それ以外の未達は半透明の候補。間隔期限が来ている場合は週に余裕があっても必須です。今日完了済みは完了扱いです。


## 履歴とパワーグラフ
ナビはToDo・達成状況・タスク一覧・履歴。ToDoは完了済みを非表示、履歴は完了の記録だけ表示します。取り消しは保存済みの進捗を戻し、履歴から除外します。
達成状況に通常表示とパワーグラフの切り替えがあります。定期タスクだけを名前のキーワードで語学・理系・健康・課題へ分類し、不明は課題に分類。週達成率min(1,完了回数/週目標)を各タスク同じ重みで合計します。週回数なし・間隔ありは、その週の有効日数/間隔を切り上げた回数を週目標とします。両頻度なしは定期集計から除外。グラフの最大目盛りは分野合計の最大を切り上げ、最低1とします。


## 分類とグラフ詳細（更新）
名前に『課題』と明示されたものだけを課題へ分類します（ほかの分野の単語と共存しても課題を優先）。語学・理系・健康のどれにも当てはまらない未分類タスクは通常表示には残し、パワー集計から除外します。グラフは詳細を常時表示せず、分野のラベルまたはボタンで合計ポイントと対象タスクを開きます。詳細が多い場合はページ切替。320×568と390×844でグラフ/詳細のスクロールなしを検証しました。


## 分類辞書の拡張
語学はリーディング・ライティング・読解・音読・発音・シャドーイング・各語学試験など、理系は力学・電磁気・熱力学・波動・線形代数・回路・プログラミングなど、健康は筋トレ種目・水泳・栄養・休養などを含みます。半角カナと英語名も判定します。既存のタスクも新しい辞書で再分類されます。課題は明示された場合だけ、不明は集計対象外です。

## パワーグラフの割合
各分野の全対象タスク達成を100%（軸の外周）に固定します。軸の長さは各タスクの週間達成率の和÷対象タスク数。対象なしは0%。回数による重み付けはしません。詳細には割合と現在/最大ポイントを表示します。
